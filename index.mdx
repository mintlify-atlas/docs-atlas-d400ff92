AbilityKit is a modular combat toolkit for complex game projects. Rather than locking you into a single MOBA or ARPG framework, it provides composable Unity UPM packages and pure C# runtimes that you combine according to your project's needs — skill pipelines, event-triggered rules, ECS worlds, frame sync, state sync, rollback prediction, replay recording, and server-side authoritative grains for Orleans.

## Adoption Path

<Steps>
  <Step title="Run the sample catalog">
    No configuration or server required. Run `dotnet run --project src/AbilityKit.Samples -- --list` to see 37 official samples covering beginner to intermediate topics.
  </Step>
  <Step title="Choose your capability tier">
    Start with **Foundation** (core + world.di) for basic infrastructure, add **SkillCore** for triggering and pipelines, then **BattleRuntime** for projectiles and damage, and finally **SyncRuntime** for multiplayer.
  </Step>
  <Step title="Explore the relevant demo">
    The **Console Demo** shows a full MOBA-style combat loop without Unity. The **Tiny** demo walks through state sync, frame sync, and hybrid sync step by step.
  </Step>
  <Step title="Copy the packages you need">
    Copy the relevant `com.abilitykit.*` packages from `Unity/Packages/` to your project, resolving `package.json` and asmdef dependencies. Do not import the entire repository.
  </Step>
</Steps>

<Note>
  AbilityKit is in active development. Package boundaries, APIs, and examples are continuously stabilizing. Always verify capability maturity in the relevant design docs or package documentation before shipping to production.
</Note>
